
# ZORE AI — Virtual Office

Aplikasi kantor virtual dengan 9 karakter karyawan.

## Fitur
- 9 karakter karyawan virtual.
- Kepribadian dan keahlian berbeda.
- Profil karyawan.
- Aktivitas dan animasi karakter.
- Sistem pemberian tugas.
- Rekomendasi kolaborasi.

## Teknologi
- HTML
- CSS
- JavaScript
- Vite

## Menjalankan aplikasi

npm install

npm run dev

## Build

npm run build
