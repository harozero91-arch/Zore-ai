
# ZORE AI — Virtual Office

ZORE AI adalah aplikasi kantor virtual dengan sistem karakter karyawan yang memiliki kepribadian, keahlian, dan aktivitas berbeda.

## Fitur
- 9 karakter karyawan virtual.
- Profil dan kepribadian karyawan.
- Informasi keahlian dan ciri khas.
- Aktivitas dan animasi karakter berbasis CSS.
- Pemberian tugas melalui antarmuka.
- Rekomendasi rekan kolaborasi.
- Tampilan kantor bernuansa klasik dan elegan.

## Teknologi
- HTML
- CSS
- JavaScript
- Vite

## Menjalankan aplikasi

Instal dependensi:

    npm install

Jalankan aplikasi:

    npm run dev

Membangun aplikasi:

    npm run build
